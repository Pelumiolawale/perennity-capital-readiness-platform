# Proprietary Regulatory Content

Place proprietary regulatory data files in this folder.

Files here are gitignored and will never be committed.

## Format

Each file should follow the same JSON structure as the public framework files in `../frameworks/`.

## Examples of content suitable for this folder
- Internal benchmark data
- Client-specific regulatory interpretations
- Proprietary scoring adjustments
- DFI-specific criteria (IFC, AIIB, IsDB, etc.)
- Confidential deal-level thresholds
