## What still needs attention

### Immediate (before showing a client the PDF)

1. **c4 partially_aligned** — the EU Tax DNSH adaptation criterion returns `partial` because the climate-risk methodology field on the engagement (`"EU Taxonomy Appendix A..."` free text) passes the boolean gate but the v3.5 DNSH adaptation scorer treats it as "evidence present but not independently verified." To reach c4 aligned, the EU Tax inputs need to be strengthened (independent audit of the climate-risk assessment, or TNFD LEAP assessment).

2. **Visual inspection of the deployed PDF** — Vercel auto-deployed from `9070f7f`. Navigate to `/assessment/report?ref=b464da15-f122-4043-aa6d-f5720a0cc7f6` and confirm:
   - No "Frameworks Applied" or "Evidence Presented" pages (SFDR-only label; they were skipped)
   - No "Conclusions" page (also skipped)
   - SFDR section pages render c1–c7 with the new aligned/partially_aligned verdicts
   - Footnote 1 has no duplicate Article 26 parenthetical
   - No footnote text is truncated mid-word

3. **Snapshot under SFDR labels** — test by running a free diagnostic from `/assessment/snapshot` with `target_label` set to `sfdr_article_8` or `sfdr_article_9` in the intake wizard. Heatmap should now include SFDR criterion cells (entity-axis ones showing `insufficient_evidence` since Snapshot has no entity intake).

### Follow-up work (not blocking production)

4. **Legacy JSON-blob fields** — `sfdr_entity_disclosures` and `sfdr_pai_data` are retained as back-compat fallbacks. Once Dolapo confirms the discrete-column workflow works for live engagements, these can be emptied or the fallback path removed from the adapters (one-line change per adapter).

5. **c6 Taxonomy claim for real engagements** — the 11 c6_* columns exist and the adapter is wired; no engagement has ever populated them since no DC developer to date has made a Taxonomy alignment claim. When one does, Dolapo populates the c6_* columns per the checklist; c6 will return a real verdict.

6. **Airtable Interface views** — the 37 new columns and 6 child tables are navigable in the grid but would benefit from a custom Interface form grouping fields by criterion. Dolapo-polish item, not a code change.

7. **Art 9 c8/c9/c10 verdicts** — still landing at not_aligned for this engagement. The engagement data has the right structure; the verdicts are honest. c8's dominance test now has all three booleans = true (seed updated this session), but c10 PAI data lacks methodology references. Improving those values is a data quality issue, not a code issue.

8. **`docs/engagement-call-checklist.md`** — Dolapo should review and adjust the question wording to match how he actually phrases things in calls. The checklist is a starting point, not a final deliverable.
